# Mario Like 2D platformer prototype.

### Every system in this project was developed from scratch using only C++ standard library.  
*Except opening window and drawing a texture on a specific point of the screen, which was implemented using SDL 3.4.0*  

List of working game systems:
* Rendering, 
* Camera, 
* Movement, 
* Gravity, 
* Collision, 
* Jump and Dash

---

### This project can be used as a basic engine for any 2d platformer
What you can customize without toching code:
- Loading different maps using csv format
- Tileset loading using only "path" variable in config
- Changing game data, mechanics using config file
